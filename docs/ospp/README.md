# 开源之夏（OSPP）专区

> 开源之夏（Open Source Promotion Plan, OSPP）是由中科院软件所"开源软件供应链点亮计划"发起的学生开源活动。本页是 NEC 社区参与 OSPP 的统一入口。

## 我们是谁

NEC（New Energy Coder Club）是面向 **RISC-V × 边缘 AI**（KPU/NPU 推理 × 机器人 × 星闪互联）的开源实践社区，依托 openEuler Embedded / RT-Thread 生态，已有多次 OSPP 参与与结项经验。
