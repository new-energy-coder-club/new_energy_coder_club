# 星闪手柄 · 成员开发日志

> 从原 readme.md 迁移（2026-09），保留原始排障记录，供新成员参考。

## 杨力滔

- **4.20** 正式开始安装相关环境，WSL 子系统开发环境搭建。一开始没找到下载的 fbb_ws63_wsl，最后将它拖到桌面上找到了文件路径；在 PowerShell 中要更新 WSL 子系统不然不能使用。
- **4.26** 星闪代码下载，将星闪代码导入 VSCode，对星闪代码编译。
- **4.27** 进行镜像烧录：Type-C 线将板端与 PC 端连接，安装驱动"CH341SER 驱动"，下载烧录工具进行烧录，发现总是失败。
- **4.28** 解决不能烧录问题：有的板子需要插拔后才可以烧录成功。进行虚拟机开发环境部署，下载项目代码和安装 SDK，然后进行项目代码编译。
- **4.29** 进行小车端组网配置和域 id 配置。
- **4.30** 对海鸥派进行开发和使用，进行 EulerPi 镜像下载。镜像文件包括 Uboot、kernel 和 rootfs，需要拷贝到 SD 卡给海鸥派升级。过程中遇到了问题，发现可能是拷贝镜像文件到 SD 卡未正确创建分区表或文件系统，我们直接使用 dd 写入完整镜像：`sudo dd if=image.img of=/dev/sdX bs=4M status=progress`。
- **5.1** 下载 Uboot 二进制包，然后下载海鸥派普通版本镜像。
- **5.2** 对海鸥派进行镜像烧录。先快速构建出一个 openEuler Embedded 镜像：需要在构建主机上安装必要的主机包，初始化 oebuild 构建环境，然后执行命令进行 ARM64 QEMU 镜像的构建（build_arm64 为该镜像的构建目录），在主机上通过命令安装 QEMU。
- **5.3** 完成基于 SDK 的应用开发：进入到镜像构建目录 build_arm64，执行命令构建 SDK 卡，安装依赖软件包，执行 SDK 自解压安装脚本，然后设置 SDK 环境变量并检查是否安装成功。
- **5.6** 了解手柄电路的设计：遥控器底板模型总体按照 PCB 轮廓构建，使用 Autodesk Fusion 进行建模；顶层亚克力板轮廓由底板模型轮廓构建，使用 Fusion 进行导出。
- **5.7** 购买 PDB 电子元器件物料。
- **5.8** 先试着调试 1.0 星闪手柄。
- **5.9** 所有材料到齐，准备进行焊接，从贴片元器件开始，找到要焊接的元器件型号。
- **5.10** 用万用表检查有没有焊接错误的地方。遇到问题开机后休眠，检查后发现是虚焊。
- **5.11** 将硬件总装，对软硬件进行调试，完成任务。成品照片见 [readme.md](./readme.md)「星闪手柄实操展示」。
