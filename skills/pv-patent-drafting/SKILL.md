# 光伏软件专利全流程撰写

六阶段流水线：**查新检索 → 交底书 → 权利要求书 → 附图 → 说明书 → 交付物（模板 docx / 立项 PPT）**。每个阶段有固定输出文件与质量门槛，详细方法论见 [references/workflow.md](references/workflow.md)。

## 前置原则

- 一切权利要求必须锚定**代码级真实实现**，先用代码探索（如 explore agent）提取技术特征，禁止虚构实施例。
- 查新先行：未做现有技术检索不得起草权利要求；独权必须落在检索空白区。
- 专利新颖性是绝对标准：任何优先权日前的公开（含软件手册、招股书、论文）都算现有技术。
- 若产品已公测/开源，首先核实功能首次公开日期，评估新颖性宽限期风险并提示尽快申请。

## 阶段与输出

所有中间产物写入项目 `patent/` 目录：

| 阶段 | 输出 | 要点 |
|------|------|------|
| 1 查新 | `PRIOR_ART_REPORT.md` | 中英文关键词 + Google Patents/CN 转载页/学术论文/竞对产品手册；输出"技术特征×现有技术"对照矩阵，标注每条特征的新颖性强弱 |
| 2 交底书 | `INVENTION_DISCLOSURE.md` | 问题-方案-效果框架；核心构思（独权范围）/支撑特征（从权）/可选特征（实施例）三层分解；附图计划；与最接近现有技术对比表 |
| 3 权利要求 | `CLAIMS.md` | CN 两部式、独从权混编连续编号；方法+系统+存储介质多主题；每条从权是独立退守位；不写结果性限定 |
| 4 附图 | `figures/*.svg` + PNG | 黑白线条、SimSun、统一附图标记对照表；SVG 可编辑源文件必须保留 |
| 5 说明书 | `specification/` 分节文件 + `SPECIFICATION_INDEX.md` | 分节撰写（名称/领域/背景/内容/附图说明/实施方式/摘要≤300字）；做"权利要求→说明书支撑核查表"，零缺失 |
| 6 交付 | docx 模板 + PPT | 用 `scripts/` 中脚本自动填写企业模板、插入立项 PPT 知识产权页 |

## 脚本使用（scripts/）

> 依赖 docx skill 的 WIR 引擎（Linux 编译产物）：在 WSL 中准备 Python 3.12 + `pillow lxml python-pptx`（可用 uv），并用 `runpy.sh <script>` 包装执行，避免 Git Bash 路径转换问题（`MSYS_NO_PATHCONV=1 wsl -e bash runpy.sh xxx.py`）。

- `scripts/fill_disclosure.py` — **天合富家技术交底书 docx 模板自动填写**（含完整工作示例）：按段落 P 键替换技术内容、替换/追加附图、图片转"上下型环绕"。新发明复用时：改 `SRC/OUT` 路径与 `EDITS` 列表（段落键 → 新文本）。填写前必须先读模板 WIR 结构确定 P 键。
- `scripts/crop_figs.py` — 附图 PNG 白边自动裁剪（PIL 内容包围盒），嵌入 docx/PPT 前必跑。
- `scripts/add_patent_slide.py` — 向立项 PPT 指定页后插入"知识产权布局"页（36pt 页眉标签 + 左侧要点 + 右侧附图），并把新页移动到正确位置。
- `scripts/runpy.sh` — WSL 执行包装器。

## 附图规范

- 流程图、系统框图、原理示意图、实施效果对比图为必备四类；每张图内嵌图号标题（如"图1 ……流程图"）。
- 渲染验证：用 Edge/Chrome 无头截图 `--headless=new --screenshot=out.png --window-size=1100,1050 file:///abs/path.svg`，逐张目检文字裁切与遮挡后再嵌入。
- 嵌入尺寸：A4 版心宽约 14.7cm，横向图取 14.1cm，纵向图高度 ≤ 21cm 防跨页。

## 避坑清单（来自实战）

1. 商用软件公开手册（如华为 SmartDesign 运维通道）也是现有技术，相关特征不得进独权。
2. "分组检修通道""旋转网格+角点校验""逐时阴影外包"等已是拥挤区；独权要找检索空白（本案为"图案掩膜排布"）。
3. docx 填写时发明人个人信息默认保留模板原值，交付时提醒用户确认。
4. 对比现有技术的效果论述应引用一线业务痛点（如内部工具调研结论），竞品名在申请文件中泛化处理。
5. OneDrive/Word 打开中的文件无法写入，输出到本地目录或提醒用户关闭。
